# ShopOps — Digital Operations Management Dashboard

A responsive front-end project designed for a **Digital Operations Management Intern** role. It simulates a small e-commerce operations workspace for product listing, catalogue management, SEO checks, and quality control.

## Features

- Product catalogue with search and status filters
- Add and edit product listings
- Product status management: Draft, Review, Published
- Listing completeness and SEO-readiness metrics
- Quality checklist with progress indicator
- SEO issue summary: missing meta descriptions, short descriptions, missing alt text, and missing tags
- CSV export for operational reporting
- Responsive layout and light/dark theme toggle
- Browser localStorage persistence

## Skills demonstrated

- HTML5 semantic structure
- CSS responsive UI design
- JavaScript DOM manipulation and event handling
- Form validation and CRUD-style operations
- Data quality checks and operational reporting
- Basic SEO concepts: titles, meta descriptions, image alt text
- CSV generation and export

## How to run

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Add or edit products and test the filters, quality checks, and CSV export.

No framework or installation is required.
